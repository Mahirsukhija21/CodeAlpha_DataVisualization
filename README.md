# CodeAlpha_DataVisualization

Data Visualization for the CodeAlpha Data Analytics Internship (Task 3).

## Dataset
1,000 books scraped from books.toscrape.com (see CodeAlpha_WebScraping). Columns: title, price, rating, availability, detail_url, category, upc.

## What's inside
- `visualization.ipynb`: six charts, each with a short takeaway
- `charts/`: the charts saved as PNG images
- `books_full.csv`: the dataset

## Charts
1. Top 10 categories by number of books
2. Price distribution
3. Rating distribution
4. Price by rating (box plot)
5. Average price by category
6. Rating share by category (heatmap)

## Key finding
Price, rating and category show no meaningful relationship in this dataset.

## Tools
Python, pandas, Matplotlib, Seaborn (run in Google Colab)
